# Semi-Classical Estimates of Enzymatic Quantum Tunneling: A Reproducible WKB Framework

An automated computational pipeline integrating a one-dimensional Wentzel-Kramers-Brillouin (WKB) approximation with evolutionary protein language modeling to estimate particle transmission probabilities and evaluate mutation sequence compatibility.
