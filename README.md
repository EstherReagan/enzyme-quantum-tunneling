# ⚛️ Enzyme Quantum Tunneling: A Reproducible WKB Framework

An automated computational pipeline integrating a one-dimensional Wentzel-Kramers-Brillouin (WKB) approximation with evolutionary protein language modeling. You can find the full markdown and documentation structure in the referenced repository.

### 📄 Official Publication & Citation Baseline
Indexed on Zenodo (DOI: 10.5281/zenodo.22813021).

## 🔍 Overview
Investigates quantum tunneling in enzymatic reaction mechanisms, addressing kinetic isotope effects (KIE) and transition-state models.

## 🔬 Scientific Foundation
Evaluates transmission probability via the WKB approximation with corrected GitHub Markdown math rendering syntax.

## 📂 Project Architecture
Contains a clean, single-directory layout including `manuscript.tex`, `wkb_tunneling.py`, `requirements.txt`, `LICENSE`, and `README.md`.

## ⚙️ Quick Start & Execution
Clone the repository, set up the virtual environment, install dependencies from `requirements.txt`, and run `python wkb_tunneling.py`.
